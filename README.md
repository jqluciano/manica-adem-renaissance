# Manica ADEM Renaissance

Reconstrói o website institucional da ADEM — Agência de Desenvolvimento Económico de Manica — numa aplicação React moderna, responsiva e profissional. Existe um repositório importado que deve ser usado apenas como fonte de conteúdo, imagens e referências visuais: procura e reutiliza imagens adequadas das pastas Gallary, images e img. Não uses ASP.NET Web Forms nem ficheiros .aspx como base de execução. Cria página inicial moderna com cabeçalho responsivo e menu móvel; secções missão, impacto, áreas estratégicas, projectos, notícias e contacto; rodapé com morada, telefone, e-mail e redes sociais; paleta verde escuro, verde ADEM, branco e apontamentos amarelo-esverdeados; acessível, rápida e mobile-first. Inclui páginas Sobre nós, Projectos, Notícias, Publicações, Galeria e Contacto. Usa conteúdos reais do repositório quando disponíveis e assegura navegação funcional entre páginas.
